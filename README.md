## Tech stack

Python, NLTK, Gensim, TensorFlow / Keras, TensorFlow Hub & TensorFlow Text, Hugging Face Transformers, scikit-learn

## Run locally

```bash
git clone https://github.com/amitmohanty022/Deep-Learning-NLP-for-ML-NLP-for-DL.git
cd Deep-Learning-NLP-for-ML-NLP-for-DL
pip install jupyter nltk gensim tensorflow tensorflow-hub tensorflow-text transformers scikit-learn pandas tqdm
jupyter notebook
```
